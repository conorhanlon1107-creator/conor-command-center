# Conor Command Center ✨

A simple, mobile-friendly personal dashboard for tasks and notes. It works as a static website without a server, account, API key, or build step.

## Run it

Open `index.html` in a browser. Add tasks, filter by category, check them off, and keep notes. Data is saved in **this browser's localStorage**, not synchronized across devices. Click **Export data** for a JSON backup.

## Publish with GitHub Pages

1. Open **Settings → Pages** in your repository.
2. Choose **Deploy from a branch**, then select `main` and `/ (root)`.
3. GitHub will show the published URL after deployment.

**Privacy:** The sample content is generic. Tasks and notes remain in the visitor's own browser, but don't enter passwords or sensitive identifiers. Browser storage can be cleared and isn't a secure vault.
